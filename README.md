# retailquant — 面向散户的 A 股量化交易工具

一个立足**散户真实交易环境**的轻量级量化回测工具：低频日线策略、真实交易成本、
纪律化风控，帮助散户用数据验证"这个方法到底赚不赚钱"。

## 立足散户的设计

| 散户特点 | 工具设计 |
|---|---|
| 本金小（默认 6 万） | 整手（100 股）交易、佣金最低 5 元按实收取；买不起一手的高价股如实放弃 |
| 白天上班没时间盯盘 | 日线级策略：收盘后看信号，次日开盘下单 |
| 无融券/高频通道 | 只做多、不做空、不搞高频 |
| 拿不住/不止损 | 引擎内置硬止损 -8% / 止盈 +20% 纪律 |
| 容易忽视成本 | 佣金万2.5 + 卖出印花税 0.05% + 过户费 + 滑点全计入 |
| 遇到涨跌停 | 开盘涨停不追买、跌停无法卖出，如实模拟 |
| T+1 制度 | 当日买入当日不可卖（含止损） |

## 内置策略

- `dual_ma` 双均线（MA5/MA20 金叉死叉）— 趋势跟随入门
- `macd_cross` MACD 金叉（带零轴过滤）— 减少震荡市假信号
- `rsi_reversal` RSI 超卖反转 — 震荡市抄底，靠硬止损兑底
- `donchian` 海龟/唐奇安通道突破（20/10 日）— 经典趋势跟踪，低胜率高盈亏比
- `boll_reversion` 布林带均值回归 — 跌破下轨收回买入、回归中轨卖出，震荡市高胜率
- `momentum` 20 日动量择时 — 动量转正买入转负卖出，ETF 轮动类策略的单标的版
- `buy_and_hold` 买入持有 — 基准对照，检验策略是否跑赢“拿着不动”

## 风控档位（来自 AI 产业链对照实验）

| 档位 | 止损/止盈 | 适用场景 |
|---|---|---|
| 纪律版 | -8% / +20% | 低波动蓝筹 |
| 宽松版 | -15% / +50% | 高波动股 |
| 趋势版 | -15% / 不止盈 | 热门趋势股（靠策略信号离场） |

## 快速开始

```bash
pip install -r requirements.txt

# 方式一（推荐）：Web 界面，浏览器打开 http://localhost:8501
python -m streamlit run retailquant/webapp.py

# 方式二：命令行。默认：长江电力/五粮液/中国平安/招商银行，2022-2025 四年回测
python -m retailquant.main

# 命令行自定义
python -m retailquant.main --symbols 600900 000858 --start 20230101 --end 20251231 --strategies dual_ma buy_and_hold
```

Web 界面三个页签：
- **策略回测**：自选股票/区间/策略多选对比、本金与止损止盈可调、绩效热力总表、
  净值曲线对比图、逐笔交易明细与 CSV 下载（输入代码后侧栏实时显示识别到的股票名称）。
- **持仓助手**：手动录入真实持仓（代码/股数/成本价/现金，股数 0 = 观察股），
  逐只指定策略与风控档位，一键生成基于最新收盘的“明日操作建议”
  （买入股数/止损止盈参考价/离场信号/逼近止损预警，建议表含股票名称）；持仓保存在 `portfolio.json`。
- **个股速览**：全市场搜索选股（代码/名称均可筛），展示最新价/行业/市值/上市时间等基本情况，
  并提供东方财富/同花顺/巨潮资讯的行情、公告全文、F10 资料外链。

输出：
- `output/regression_report_*.txt` 多标的 × 多策略绩效对比报告
- `output/trades_*.csv` 每笔交易明细（买卖点/离场原因/盈亏），便于复盘
- `data_cache/` 行情本地缓存（akshare 免费数据，前复权）

## 工程结构

```
retailquant/
  config.py      # 全部参数集中管理（费用/风控/回测环境），无散落魔法数字
  logger.py      # 统一日志（控制台 + 文件）
  data.py        # akshare 取数 + 缓存 + 数据质量校验
  indicators.py  # 纯函数向量化指标：SMA/EMA/MACD/RSI/BOLL/ATR
  strategy.py    # 策略基类 + 4 个内置策略（防未来函数）
  backtest.py    # 事件式回测引擎（T+1/整手/涨跌停/全费用/止损止盈）
  report.py      # 绩效指标（年化/夏普/回撤/胜率/盈亏比）与报告输出
  portfolio.py   # 持仓管理（手动录入 + JSON 持久化）
  advisor.py     # 操作建议引擎（止损/止盈/策略信号 -> 明日操作，T+1 语义）
  stockmeta.py   # 个股名称/基本情况查询 + 东方财富/同花顺/巨潮外链（纯逻辑可单测）
  main.py        # CLI 入口
  webapp.py      # Web 服务（Streamlit 三页签，只做展示层，业务逻辑全部复用）
tests/           # 85 个单元测试：pytest 一键运行
```
